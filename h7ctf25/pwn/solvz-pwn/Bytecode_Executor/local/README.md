# Secure Bytecode Executor

## Challenge Description

We've built a secure bytecode execution environment. Submit a custom compiler and input file, and we'll execute the generated bytecode after strict verification.

Only safe instructions are allowed. Can you read the flag?

## Connection

```bash
nc <host> <port>
```

## Protocol

The service expects two files in sequence:

1. **Compiler executable** (first)
   - Send file size as decimal number + newline
   - Send file contents

2. **Input file** (second)
   - Send file size as decimal number + newline  
   - Send file contents

**Example:**
```python
# Send compiler
compiler = open("my_compiler", "rb").read()
sock.send(f"{len(compiler)}\n".encode())
sock.send(compiler)

# Send input
input_data = b"whatever"
sock.send(f"{len(input_data)}\n".encode())
sock.send(input_data)
```

Your compiler will be executed with two arguments:
```
./compiler <input_file> <output_file>
```

The output file should contain bytecode that will be verified and executed.

Good luck!
